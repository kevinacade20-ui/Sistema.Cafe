☕ Sistema Café

Sistema de gestión para una cafetería desarrollado en Python, creado como proyecto para aplicar conocimientos de programación, manejo de módulos, archivos y lógica de negocio.

📌 Descripción

Sistema Café es una aplicación que permite gestionar diferentes procesos relacionados con la atención y administración de una cafetería.

El proyecto está desarrollado de forma modular, separando las diferentes funcionalidades en archivos Python para facilitar su organización, mantenimiento y comprensión.

🚀 Funcionalidades
📋 Gestión del menú de productos.
🛒 Registro y gestión de pedidos.
👤 Manejo de nombres y usuarios.
🔐 Gestión de roles.
📜 Consulta del historial de pedidos.
📊 Generación de reportes.
💾 Almacenamiento de información mediante archivos.
⚠️ Manejo de errores y validación de datos.
🛠️ Tecnologías utilizadas
Python 3
Programación modular
Manejo de archivos .csv
Estructuras de datos
Funciones
Condicionales y ciclos
Manejo de excepciones con try/except
